# Smart Display

A custom Raspberry Pi 5-powered smart display currently in active development.

The project aims to create a fully customizable touchscreen assistant with features such as voice interaction, AI integration, media controls, weather, and smart home capabilities.

## Current Status

*In Production*

Currently developing the touchscreen interface, system integrations, and hardware/software communication.

## Tech Stack

- Raspberry Pi 5
- React + Vite
- Node.js / Express
- Linux
- Nginx
- Custom 3D-printed enclosure
